# Validador de CPF

Exercício de Python para praticar strings, expressões regulares e cálculo dos dígitos verificadores de um CPF.

## Como executar

Requer Python 3:

```bash
python app.py
```

Digite o CPF com ou sem pontuação. O programa aceita apenas números, pontos, hífens e espaços; não consulta bases externas nem confirma se o documento foi emitido.
